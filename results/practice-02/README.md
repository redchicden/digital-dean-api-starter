# Результати практичної роботи 2

Після власного запуску додайте `raw.csv` (180 серій), `report.json` (36 агрегатів) і два графіки. Схема полів і методика визначені в документі практичної роботи.

Не додавайте ключі, відкриті примітки або повні набори шифротекстів. Файли результатів не мають містити готових чи вигаданих показників із заготовки. Ключі й послідовності одноразових значень існують лише в пам’яті процесу експерименту.

# Звіт з практичної роботи 3

Заповніть дані своїми результатами; не подавайте незмінений шаблон.

## Титульні відомості
Студент, група, варіант, дата, посилання на власний форк, гілку practice-03, тег practice-03 та SHA фінальної фіксації.

## Мета та продовження API
Наведіть тег practice-02, результат попередніх тестів до/після імпорту, baseline practice-03-base, перелік змінених модулів і пояснення нового маршруту. Підтвердіть спільну історію.

## Середовище та методика
Python, cryptography, OpenSSL бібліотеки, ОС, CPU; 5 серій по 20 операцій, прогрів 10, 5 генерацій ключа; порядок профілів; межі таймера; SHA коду перед експериментом; формули медіани/IQR/пропускної здатності.

## Коректність і параметри
П'ять профілів, два класи навантаження; граничні довжини RSA; 22 перевірки; відмінність OAEP label, AAD та HPKE info; відсутність автентифікації відправника у Base mode. Покажіть свої ключові фрагменти коду.

## Результати
Додайте raw.csv (130 рядків), report.json (4+22 агрегати), таблиці виміряних значень. Не менше двох графіків: час encrypt/decrypt за профілями та розмірами; розмір двійкового результату або час генерації ключа. Графік має мати одиниці, легенду, підписи та джерело своїх чисел. Порівнюйте лише однакові розміри та операції.

## API та індивідуальний варіант
Контракт, response_model, 200/404/500, за варіантом 422 або summary. Приклади JSON із власного звіту та підтвердження, що HTTP не запускає експеримент і не приймає шлях файлу.

## Перевірки
pytest, Postman, попередні регресійні тести, тести некоректної схеми, дублікатів, помилок дешифрування та свого варіанта. Не приховуйте негативних результатів.

## Git
`git remote -v`, `git log --oneline practice-03-base..HEAD`, перевірка предка practice-02, власні ≥4 змістові комміти після baseline, опубліковані теги. Імпорт і викладацькі комміти не зараховуються.

## Висновки та межі
Інтерпретуйте швидкість, накладні витрати, коректність та обмеження застосування окремо. Не робіть висновку про універсально найкращий або криптографічно сильніший алгоритм тільки з часу чи довжини ключа.

## Використані джерела
Офіційні джерела, чинні URL і дата звернення.

## Алфавітний глосарій
Поясніть використані спеціалізовані терміни та розшифруйте абревіатури англійською й українською. Виноски не потрібні.

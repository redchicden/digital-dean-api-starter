# Звіт із практичної роботи 4

## Відомості

Автор, група, дата, номер та остача від ділення на 4. Посилання на власний
форк, гілку practice-04, теги practice-04-base і practice-04, source_commit.

## Мета і реалізовані зміни

Що додано до того самого API, де розміщено адаптери, експеримент, схему й маршрут.
Опис власного варіанта та фрагменти ключових змін. Не вставляйте повний код
замість посилання на репозиторій.

## Середовище і методика

Python, ОС, модель процесора, архітектура, версія OpenSSL модуля ssl,
ідентифікатор реалізації кожного профілю, параметри повторів і прогріву,
межі таймера, статуси недоступності. Пояснення обмежень такого вимірювання.

## Результати

Посилання на raw.csv, avalanche.csv і report.json. Таблиці медіани та IQR,
пропускної здатності, розмірів хешів, відстаней і часток змінених бітів.
Не менше двох графіків: швидкодія та спостережуваний лавинний ефект.
Відсутні значення не замінюйте нулями. Час HTTP не підміняє час хешування.

## API та перевірки

Контракт нового GET, приклад JSON з власного запуску, OpenAPI, власний варіант,
результати pytest і Postman, негативні випадки, попередні регресії.
Пояснення невдалих діагностичних перевірок, якщо вони виникали.

## Історія Git

Доказ спільної історії з practice-03, baseline, щонайменше чотири власні
змістові комміти після baseline, source_commit у предках фінального тегу.

## Висновки та межі

Висновки лише для перевіреного середовища, реалізацій та розмірів. Відокремте
швидкість, правильність обчислення й відомі криптографічні властивості.
Поясніть роль довіреного контрольного значення і непридатність звичайного
швидкого хешування як достатнього захисту паролів.

## Використані джерела

Офіційні URL і дати звернення; не подавайте параметри роботи як універсальні.

## Алфавітний глосарій

Власні визначення використаних термінів і розшифрування абревіатур.
Для англійських абревіатур: повна назва, український відповідник, контекст.
Виноски не використовуються.

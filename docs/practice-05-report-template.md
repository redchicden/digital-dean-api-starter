# Звіт до практичної роботи 5

## Мета та власний результат
Вкажіть той самий форк і гілку practice-05, початковий practice-05-base та
фінальний анотований тег practice-05. Опишіть свої зміни, не готовий каркас.

## Середовище та база
Версії Python, SQLite, FastAPI, Pydantic. Шість таблиць, схема зв'язків,
первинні/зовнішні ключі, обмеження і точні довідники. Покажіть повторний запуск
ініціалізації без втрати синтетичних записів. Файл бази не долучайте.

## Захист паролів
PBKDF2-HMAC-SHA256, 600000 ітерацій, 16 байтів солі, 32 байти результату.
Поясніть формат запису, обмеження параметрів, випадковість солі, точний UTF-8,
compare_digest і межі цього профілю. Продемонструйте відмінність результатів
для однакового вигаданого пароля, не публікуючи дамп облікових даних.

## Реалізація API
Чотири функції register_user, delete_user, block_user, login у наявному API.
Укажіть шляхи, коди, безпечні відповіді. login повертає JSON boolean і дозволяє
вхід лише active. Покажіть 204 без тіла, ідемпотентне блокування та 409 за
оцінками; дані і зв'язки ролей після забороненого видалення зберігаються.

## Перевірки
Власні pytest на тимчасовій базі, Postman, негативні випадки, цілісність,
відсутність секретів у відповідях/помилках/журналах, перезапуск процесу,
збереження попередніх маршрутів і тестів. Наведіть спостережені результати,
не стверджуйте проходження перевірки без фактичного виконання.

## Історія Git
Щонайменше чотири власні змістові коміти після practice-05-base. Посилання
на той самий origin, гілку й теги, журнал власних змін, підтвердження спільної
історії з practice-04 та відсутності бази/секретів у версіонованих файлах.

## Висновки та межі застосування
Стійкість до перезапуску не є шифруванням бази. Роль не дорівнює статусу.
Зовнішній ключ не перевіряє роль викладача. Булевий login не створює сесію
і не авторизує адміністративні методи. Сервер тільки локальний.

## Офіційні джерела
Додайте використані чинні URL і дату звернення.

## Глосарій
Алфавітний словник абревіатур і термінів із повними назвами та українськими
поясненнями. Виноски в практичній роботі не потрібні.
